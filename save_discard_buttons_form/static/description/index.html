Save / Discard Buttons Form

Make the Save and Discard buttons on Odoo forms impossible to miss

Why this module?

By default, the Save and Discard controls on Odoo 17 forms are small, low-contrast icons that are easy to overlook, especially for new users. This module restyles them to be immediately recognizable, reducing accidental data loss and confusion about unsaved changes.

Features

  • "Save" button highlighted in green, both in the control panel and in the status indicator (breadcrumb)
  • "Discard" button highlighted in red outline, both in the control panel and in the status indicator
  • Clear hover/focus states so the active action is always obvious
  • "Save" and "Discard" text labels added next to the status indicator icons
  • The Actions (cog) menu button gets a visible, consistent button style
  • Purely visual: no changes to save/discard behavior, no new fields or settings

Usage

  1. Install the module
  2. Edit any record in a form view
  3. The Save and Discard buttons appear in their new, more visible style automatically
